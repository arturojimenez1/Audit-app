# Audit-app

Plataforma de Auditoría Empresarial construida con Laravel, Inertia.js, Vue 3, Tailwind CSS y Docker.

## Tecnologías y Características
- **Backend:** Laravel 11 / 12 + PHP 8.4 (OPcache optimizado)
- **Frontend:** Vue 3 + Inertia.js + Tailwind CSS + Plus Jakarta Sans
- **Contenedores:** Docker Compose (Nginx, PHP-FPM, MySQL 8.4, Node Vite)
